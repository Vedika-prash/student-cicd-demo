# Student CI/CD Demo

## Project Overview
This project demonstrates the implementation of a Continuous Integration and Continuous Deployment (CI/CD) pipeline using GitHub Actions.

## Objectives
- Automate code quality checks using linting.
- Run automated unit tests.
- Validate application changes through a CI/CD workflow.
- Demonstrate automated software testing and integration.

## Technologies Used
- Python
- Git and GitHub
- GitHub Actions
- Flake8
- Nose testing framework

## Project Structure
- `.github/workflows/` — GitHub Actions workflow configuration.
- `app.py` — Application code.
- `test_app.py` — Unit tests.

## Workflow
1. Developers push code to the GitHub repository.
2. GitHub Actions automatically starts the workflow.
3. The workflow checks code quality and executes unit tests.
4. The workflow reports whether the checks passed.
